# Maintaining the September experimental branch

- Read `README.md` and `docs/september-calibration.md` before modifying a
  calibration or hardware workflow. This branch is not the August 25 demo
  baseline on `main`.
- Read the author's private calibration-investigation ledger when available.
  Use completed tests and operator corrections before proposing another
  investigation. Missing local evidence does not mean a test never happened.
- No September candidate was deployed. Wrist patches remain unapplied, the
  vendor issue draft and broader sweep are paused, and adding a forearm marker
  was rejected for lack of mounting space. Historical proposals are not a work queue.
- Preserve shared runtime dependencies and distinguish offline regressions from
  physical commissioning. The final operator-preclosed lifecycle still requires
  hardware validation and cannot reuse earlier grasp-posture route certificates.
- Personal running notes and internal proposals/implementation plans are private.
  Keep them in ignored local storage or an explicitly private repository.
- Code review and documentation do not authorize operating the robot.
